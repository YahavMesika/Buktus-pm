# שלום בוקטוס · ניהול פרויקטים

מערכת לניהול משימות, פרויקטים וקבלני משנה, עם עדכון מהיר מהשטח ותצוגה לפגישה השבועית.

- `index.html`, `styles.css`, `app.js`: האתר.
- `firebase-config.js`: ההגדרות של פרויקט ה-Firebase (מדביקים מהקונסול).
- `seed.js`: נתוני הפתיחה מהפגישה של 22.11.2026.
- `firestore.rules`: חוקי האבטחה. מדביקים אותם ב-Firestore ← Rules, עם המיילים המורשים.

האחסון: GitHub Pages. ההתחברות ומסד הנתונים: Firebase (Google sign-in + Firestore).
